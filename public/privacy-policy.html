파기

회원 탈퇴가 정상 처리되면 서비스 데이터베이스의 계정·프로필·관리 기록·가족 연결·동의·권리 요청 기록을 삭제합니다. 건강정보 동의 철회 시 건강 기록과 가족 공유를 삭제·중단합니다. 전자 기록은 데이터베이스 삭제 기능으로 처리합니다. 현재 무료 프로젝트에는 운영자가 복원하는 자동 백업이 포함되지 않고 외부 로그 전송과 인증 감사 로그의 DB 추가 저장은 사용하지 않습니다. Supabase 요금표상 API·DB 로그 조회 기간은 1일, 인증 감사 로그는 1시간입니다. 이는 제공업체 내부 보안 로그·복제본까지 같은 시점에 삭제된다는 뜻은 아닙니다. 제공업체 내부 기록은 해당 업체의 계약·보안·법적 보존 기준에 따라 처리됩니다. Vercel은 서비스 제공·보안·법적 의무에 필요한 최소 기간 동안 접속 관련 정보를 보관하며 필요가 없어지면 삭제 또는 익명화한다고 안내합니다. 이용자는 위 문의처로 삭제 및 잔존 기록 확인을 요청할 수 있습니다. 문의 이메일에 포함된 내용은 문의 처리 완료 후 30일 내 삭제하는 것을 운영 기준으로 하며, 별도 보존이 필요한 경우 대상·근거·기간을 안내합니다.

안전성 확보조치

HTTPS 통신과 사용자 인증을 사용합니다. 서비스 테이블에 행 수준 보안(RLS)을 적용하고 가족 연결·동의 상태에 따라 조회를 제한합니다. 개인정보 동의·권리 요청 테이블은 클라이언트의 직접 접근을 제한하고 허용된 서버 함수로 처리합니다. 비밀번호는 인증 서비스가 처리하며 가족에게 제공하지 않습니다. 공개 웹 코드에는 서버 관리자 비밀 키를 포함하지 않습니다. 운영자는 업무상 필요한 범위에서만 관리 권한을 사용합니다.

처리위탁

Supabase: 계정 인증, 서비스 데이터베이스와 실시간 조회. 주 데이터베이스는 싱가포르(ap-southeast-1)이며 별도 SMTP 업체를 연결하지 않고 기본 인증 메일 기능을 사용합니다. Vercel Inc.: 웹 화면 파일의 호스팅·전송과 접속 보안. 건강 기록 API는 브라우저에서 Supabase로 직접 전송되며 웹 파일에 건강 기록을 넣지 않습니다. 문의 이메일은 Gmail을 통해 접수하므로 Google의 이메일 서비스에서도 처리됩니다.
