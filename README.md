# 🦷 틀니케어 (DentureCare)

> 틀니 사용자를 위한 일일 관리 루틴 · 치과 검진 알림 · 가족 연동 앱

**웹 앱:** [틀니케어](https://myun-hazel.vercel.app)

아이폰 검수는 [Xcode 설치 안내](README_설치방법.md), 출시 준비는 [점검표](RELEASE_CHECKLIST.md)를 참고하세요. 이 검수 브랜치의 변경은 운영 웹 배포와 별개입니다.

현직 치과위생사(7년차)가 임상에서 마주한 문제 —
"틀니 관리법을 알려드려도 집에 가면 잊어버리시고, 검진 시기를 놓쳐 잇몸이 상한 뒤에야 오신다" —
를 해결하기 위해 직접 기획하고 개발한 앱입니다.

---

## 무엇이 다른가

### 1. 틀니 제작 시기에 따른 검진 주기 자동 계산

기존 기획에 따른 참고 주기를 계산합니다. 아래 간격과 근거, 세정·보관 안내와 건강보험 팁은 출시 전 임상 검수 대상이며 담당 치과의 개별 안내가 우선합니다.

| 사용 기간 | 단계 | 권장 검진 주기 | 근거 |
|---|---|---|---|
| 0~3개월 | 적응기 | **1개월** | 점막 적응기, 외상성 궤양 발생 위험 |
| 3~12개월 | 급격 흡수기 | **3개월** | 첫 1년 골 흡수가 가장 빠름 (Tallgren, 1972) |
| 1~5년 | 안정기 | **6개월** | 정기 점검 및 이장(relining) 검토 |
| 5년 이상 | 장기 사용 | **6개월** | 의치 부적합·연조직 병변 위험 증가 |

사용자는 틀니 만든 연·월만 입력하면 나머지는 앱이 계산합니다.

### 2. 하루 5회 근거 기반 관리 루틴

| 시점 | 관리 내용 | 주의사항 |
|---|---|---|
| 기상 후 | 입을 헹구고 틀니 장착 | 미온수 |
| 매 식후 (3회) | 1분간 솔질 | **주방세제 사용, 치약(연마제) 금지** |
| 취침 전 | 찬물에 완전히 담가 보관 | 25℃ 이하 |

치약의 연마제가 의치를 마모시킨다는 점 등, 실제 임상 지도 내용을 그대로 반영했습니다.

### 3. 가족 연동 — 이 앱의 핵심

고령 사용자 혼자서는 관리 지속이 어렵습니다. 6자리 초대코드로 자녀·배우자를 연결하면:

- 앱을 열면 부모님의 오늘 관리 현황을 확인하고 주기적으로 갱신
- 도움 요청(잇몸 통증, 틀니 파손 등)을 **보호자 앱에서 확인**. 앱이 닫힌 상태의 푸시 전달은 미구현
- 보호자는 **읽기 전용** — 데이터베이스 차원에서 강제 (RLS)

### 4. 고령자 접근성 우선 설계

본문 18px 이상(설정에서 22px로 확대 가능) · 터치 영역 48px 이상 · 한 화면 한 과업 ·
전문 용어 배제("리콜" → "치과 가는 날")

### 5. 건강보험 정보 안내

만 65세 이상 사용자에게 틀니 유지관리 건강보험 적용 항목(이장·개상·조직조정·수리 등 15종)을
하루 한 가지씩 안내합니다. 대부분의 어르신이 모르고 지나치는 혜택입니다.

## 프로젝트 구조

```
├── src/
│   ├── screens/      화면 컴포넌트 (인증·온보딩·홈·진행률·검진·설정)
│   ├── lib/          도메인 로직 (검진 주기 계산·연속일수·건강보험 정보·알림)
│   ├── state/        전역 인증 상태
│   └── components/   공통 UI (고령자 접근성 기준 적용)
├── db/migrations/    데이터베이스 스키마 + 보안 정책 (SQL)
├── docs/설계/        설계 문서 (화면·시나리오·데이터 모델·API 명세)
└── ios/              iOS 네이티브 프로젝트 (Capacitor)
```

## 로컬에서 실행하기

```bash
npm ci
```

`.env.example`을 복사해 `.env`를 만들고 Supabase 접속 정보를 입력합니다.

```bash
npm run dev
```

데이터베이스는 `db/migrations/`의 적용 순서를 [설치 안내](README_설치방법.md)에서 확인하세요. 기존 DB에 `001`을 다시 실행하지 않습니다. 이번 계정 관리 기능에는 `004_account_safety.sql`이 필요합니다.

검증: `npm run verify` · Mac에서 Xcode 열기: `npm run ios:run`. 현재 소스는 `src/`이며 `app/`은 이전 프로토타입입니다.
